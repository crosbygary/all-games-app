ALL GAMES — GITHUB PAGES

Upload the CONTENTS of this folder to the root of a GitHub repository.
In repository Settings > Pages, select Deploy from a branch, main, / (root).
No build, dependencies, JavaScript, or secret keys are required.
GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

After GitHub publishes the site, use its URL plus:
  privacy.html — App Store privacy policy URL
  support.html — App Store support URL
  terms.html   — terms page linking to Apple's Standard EULA
All local links are relative, including assets, so repository subpaths work.

Public support/privacy email: cr0sby_gar@icloud.com
The contact is identified as the All Games team; no unconfirmed legal entity
or developer legal name has been invented.

BEFORE PUBLICATION
The privacy text is based on the inspected iOS project. Server-side logging,
retention, processing locations, legal bases, and individual game-provider
practices cannot be established from the client source. Confirm these with the
service operators and amend the policy as needed. Add your legal/controller
identity and any jurisdiction-specific disclosures that apply to your business.
The current draft deliberately does not claim that no data is collected or
that externally hosted games have no advertising/tracking.

Use Apple's Standard EULA only if you have not supplied a custom EULA for the
relevant App Store regions. Apple's official guidance:
https://developer.apple.com/help/app-store-connect/manage-app-information/provide-a-custom-license-agreement

This archive does not update the iOS app's existing legal links. Once the site
is live, update those links to the published addresses. The current in-app
support form is a local prototype; the website provides a working email link.
